VlmSpellchecker Dictionary – TinyMCE Plugin

Custom spell-checker plugin using wiki-language-models .
Currently set up to use the vlmspellchecker-language-model-nl-20261001 dictionary compiled from the DUTCH wiki.

How to use
  • Click the VlmSpellchecker button in the toolbar to run a spell check.
  • Unknown words get a red underline.
  • Uncommon words get an orange underline.
  • Right-click a marked word to see suggestions and replace it.
